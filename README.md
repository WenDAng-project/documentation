This repository contains the official documentation of the WenDAng project, a semantic research infrastructure developed to support the study of new forms of contemporary Chinese calligraphy within the WRITE project.

The documentation provides background information about the project, describes its semantic resources and presents practical examples of their application.

For easier navigation, please visit the [WenDAng documentation website](https://wendang-project.github.io/documentation/).

Technical documentation concerning the WRITE dataset, including its URI policy, the vocabularies used, and examples of SPARQL queries, is available in the [WRITE data repository](https://github.com/WenDAng-project/data).
